# docs/archive/ —— 归档文档

这里放**已失效或已完成使命**的文档。约定：

- 归档文档是**历史快照**：按当时的事实写，**不追改**（与 `docs/verification-log.md` 同理），
  因此也**不参与**「文档路径引用门禁」（`scripts/check-doc-refs.mjs`）的扫描。
- 每个归档文件**开头必须写明**：何时归档、为什么归档、职责由谁接管。
- 归档判据与处置方式（纳入 / 归档 / 删除）见 `docs/agent-workflow.md` §1 与 `docs/doc-index.md`。
  要"什么被归档过"的清单，看各文件头部，或 `git log -- docs/archive/`。

**归档 ≠ 删除。** 保留的理由有两个：① 解释"为什么这件事不再按老办法做"，避免有人重新发明；
② 保留当时的证据与措辞，便于追溯决策。
