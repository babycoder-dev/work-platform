# 交付文档：企业内网工作台（Work Platform UI）

> 给使用 Claude Code 的开发者：本文件是**自足的**实现说明。即使你没有参与设计过程，也应能仅凭本 README 在真实代码库中复现全部界面与交互。

---

## 1. 概述（Overview）

这是一套**企业内网工作台**的前端设计，纯内网、桌面优先、中文界面。参考飞书 / Lark 的布局范式与交互模式（不照搬其品牌色与图标），整体风格为**亮色、蓝色主调、大量留白、圆角卡片**，信息密度克制专业。

包含 6 个页面 / 模块：

| 文件 | 模块 | 说明 |
|---|---|---|
| `工作台.html` | 工作台首页 | 数据卡片 + 应用清单表格 + 常用入口 + 系统动态 |
| `审批中心.html` | 审批中心 | 审批列表（5 Tab）+ 详情抽屉 + 差异化操作 + 模板选择 + 三类表单 + 草稿箱 + 可配置审批流 |
| `组织成员.html` (+`.js`) | 组织与人员管理 | 部门树 + 成员表 + 在位状态 + 详情/编辑 + 部门管理 |
| `我的待办.html` (+`.js`) | 我的待办 | Lark 式任务列表 + 就地新建 + 拖拽排序 + 详情面板 + 工具栏 + 折叠浮层 |
| `消息中心.html` (+`.js`) | 消息中心 | 三栏布局 + 自适应详情 + IM 聊天 + 消息转任务 |
| `企业工作台设计规范.html` | 设计规范文档 | Token 色板 + 登录页 + 应用外壳 + 基础组件展示（**实现参考，非产品页**） |
| `tokens.css` | 设计 Token | 所有页面共享的 CSS 变量唯一真源 |
| `search.js` | 全局搜索组件 | 注入各模块顶栏的跨模块搜索浮层 |

## 2. 关于这些设计文件（About the Design Files）

**本包中的 `.html` / `.js` 文件是用 HTML 编写的「设计参考」——展示预期外观与行为的原型，不是可直接照搬进生产的代码。**

你的任务是**在目标代码库的既有技术栈中（React / Vue / Angular / Svelte 等）复现这些界面**，使用其既有的组件库、状态管理与工程约定。如果项目尚无前端环境，请为该项目选择最合适的框架（推荐 **React + TypeScript + Vite**，配合一个无样式或低样式的组件基座如 Radix / Headless UI，自行落地这套视觉），再实现。

原型用的是原生 HTML/CSS/JS（少量页面把逻辑拆到同名 `.js`），**没有构建步骤**——这是为了便于预览，不代表目标实现也要如此。请按你代码库的最佳实践组件化。

## 3. 保真度（Fidelity）

**高保真（Hi-Fi）。** 这些原型带有最终的颜色、字号、间距、圆角、阴影与交互细节，应当**像素级复现**。所有设计值都已在 `tokens.css` 中变量化（见第 8 节），请在你的代码库里建立等价的 token 层（CSS 变量 / theme 对象 / Tailwind config），再用 token 搭建组件，而不是散落写死的魔法值。

## 4. 全局结构与共享外壳（App Shell）

所有产品页共用同一套「应用外壳」，**强烈建议先把它做成一个布局组件**，各模块作为其 children：

```
┌──────────────────────────────────────────────────────────┐
│ 侧边导航 220px  │            主区 (flex:1)                  │
│ (浅色, 可折叠   │ ┌──────────────────────────────────────┐ │
│  至 64px)       │ │ 顶栏 topbar 高56px                    │ │
│                 │ │ [折叠按钮] 面包屑 ……grow…… 搜索框      │ │
│ - Logo + 名称   │ │            通知铃铛  头像              │ │
│ - 分组菜单项    │ ├──────────────────────────────────────┤ │
│   (图标+文字+   │ │ 内容区 content (浅灰底 var(--fill-1)) │ │
│    选中态+角标) │ │  白色圆角卡片承载实际内容             │ │
│ - 底部用户卡片  │ │                                       │ │
└─────────────────┴──┴──────────────────────────────────────┘
```

### 侧边导航（`.side`，宽 220px）
- 背景 `--white`，右边框 `1px solid --line-1`。
- 顶部品牌区高 56px：28×28 圆角 8px 的蓝色 Logo 方块（`--blue-500`，白色字）+ 名称（15px/600）。
- 菜单项 `.nav-item`：高 38px，圆角 `--r-sm`，左右内边距 12px，图标 17px + 文字 14px/500，色 `--ink-2`；hover 背景 `--fill-2`；**选中态** `.active` 背景 `--blue-50`、文字与图标 `--blue-600`。
- 分组标题 `.gl`：11px/600，色 `--ink-4`，字距 .4px。
- 红色角标 `.badge`：背景 `--danger`，白字 11px，圆角 full，padding 1px 6px。
- 底部用户卡片：32px 圆形头像（线性渐变 `135deg,#5285FF,#3370FF`）+ 姓名 13px/600 + 角色 11px/`--ink-4`。
- **折叠态** `.app.collapsed .side` → 宽 64px：隐藏文字与分组标题、菜单项居中只剩图标、角标收成 7px 红点。过渡 `width .22s ease`。
- 折叠由顶栏左侧的☰按钮切换：`document.getElementById('app').classList.toggle('collapsed')`。

### 顶栏（`.topbar`，高 56px）
- 背景 `--white`，下边框 `1px solid --line-1`，横向内边距 20px，子项 gap 16px。
- 左：☰折叠按钮（`.icon-btn`，34×34，圆角 `--r-sm`，hover 背景 `--fill-2`）。
- 面包屑 `.crumb`：14px，当前页 `.crumb b` 用 `--ink-1`/600，分隔符 `/` 用 `--ink-5`。
- `.grow`（flex:1）占位推开右侧。
- 搜索框 `.search-box`：宽 240px，高 34px，圆角 full，背景 `--fill-1`，左侧 16px 放大镜图标；focus 时背景转白 + 蓝色描边 + 3px 光晕 `0 0 0 3px rgba(51,112,255,.12)`。占位文案统一：`搜索应用、成员、审批…  ⌘K`。
- 通知铃铛：`.icon-btn` + 右上角 7px 红点 `.dot`（未读时显示）。
- 头像：32px 圆形渐变头像，可点。

> **通知下拉 + 头像菜单 + 全局搜索** 三个顶栏组件见第 6 节，已实现，跨 5 个模块一致。

## 5. 各模块详述（Screens / Views）

### 5.1 登录页（在 `企业工作台设计规范.html` 内）
- **用途**：内网账号统一登录。
- **布局**：全屏居中。背景 `--fill-1` + 右上角极淡径向蓝光 `radial-gradient(1100px 480px at 78% -10%, #EAF1FF, transparent 60%)`。
- **卡片** `.login-card`：宽 380px，背景白，边框 `1px --line-1`，圆角 `--r-lg`，阴影 `--shadow-pop`，内边距 36/32/28。
  - 44×44 圆角 11px 蓝色 Logo（`--blue-500`）。
  - 标题「登录工作台」20px/600；副标题 13px/`--ink-3`。
  - 字段：label 13px/`--ink-2`/500 + 高 40px 输入框（`.input.input-lg`，带前缀图标，左 padding 38px）。
  - 「记住登录」复选 + 「忘记密码？」蓝色链接。
  - 主按钮 `.btn.btn-primary.btn-lg.btn-block`。
  - 底部 12px/`--ink-4` 协议提示。

### 5.2 工作台首页（`工作台.html`）
- **用途**：登录后概览，快速进入高频功能。
- **页头** `.page-head`：问候标题 20px/600 + 副标题 13px/`--ink-3`；右侧操作按钮（刷新=次要、新建申请=主要）。
- **数据卡片** `.stat-grid`：4 列（响应式 `repeat(4,1fr)`，≤1080px 转 2 列），gap 16px。每张 `.stat-card`：白底、边框、圆角 `--r-md`、内边距 18px；顶部标签 13px/`--ink-3` + 32×32 彩色图标方块；主数字 28px/700、字距 -.5px；底部 delta（涨用 `--success`、跌用 `--danger`、灰色注释 `--ink-4`）。
- **两栏区** `.two-col`：左 1.6fr 应用清单表格（见表格组件），右 1fr 含「常用入口」（2 列快捷网格）+「系统动态」（带彩色时间点的 feed 列表）。

### 5.3 审批中心（`审批中心.html`）
- **用途**：集中处理 / 发起 / 跟踪审批。
- **Tab 栏** `.tabs`：待我审批 / 我发起的 / 抄送我的 / 已处理 / 草稿箱，每个带计数 `.cnt`。选中态底部 2px 蓝条 + 文字 `--blue-600`/600。**切换 Tab 切换数据集**（不同行、不同列含义、不同行内操作）。仅「待我审批」显示行首复选框列。
- **筛选栏** `.filter-bar`：类型 / 状态 / 发起人下拉 + 重置 + 查询。下边框 `--line-2`。
- **批量操作条**（选中行后出现）：背景 `--blue-50`，显示已选数 + 批量同意 / 转交 / 取消。
- **表格**（见表格组件）：列 = 审批单(标题+单号) / 类型(Tag) / 发起人(头像+名) / 当前节点 / 金额 / 状态(Tag+圆点) / 发起时间 / 操作。点行打开详情抽屉。
- **分页器** `.pager`：右对齐，共 N 条 + 上一页/页码/下一页 + 每页条数下拉。
- **详情抽屉**（右滑 `.drawer`，宽 540px）：
  - 遮罩 `.scrim` 背景 `rgba(31,35,41,.32)`，淡入 .22s。
  - 抽屉 `transform: translateX(100%)→0`，过渡 `.26s cubic-bezier(.4,0,.2,1)`，阴影 `--shadow-drawer`。
  - 内容分区（`.d-sec`，标题左侧 3px 蓝色竖条）：基本信息（KV 网格）、报销明细、**流程时间线**。
  - **流程时间线** `.timeline`：节点圆点—已完成 `--success`+对勾 / 当前 `--blue-500`+4px 光环 / 待处理 白底灰边；每节点含姓名+角色+时间+可选审批意见气泡。
  - 底部操作条：转交（次要）/ 驳回（危险）/ 同意（主要）。
  - **三个操作走同一个确认弹窗**，但表单不同：**同意**=选填意见 textarea；**驳回**=必填理由（空提交红框拦截）；**转交**=必选转交人下拉 + 选填说明。图标/主按钮色随类型变化（同意绿/驳回红/转交蓝）。Esc 逐层关闭（先弹窗再抽屉）。
- **发起审批**：
  1. 先弹**模板选择**（按报销/请假/采购分组的卡片）。
  2. 进入**表单页**，双栏布局：左侧表单（基本信息 / 类型专属明细 / 附件 / 可配置审批流），右侧 sticky 信息栏（提交摘要含实时合计金额、审批流程竖向预览、填写须知）。
  3. **三类表单内容动态**：报销=报销明细表（可增删行、实时合计）；请假=请假类型/起止时间/时长；采购=采购明细。由顶部「审批类型」决定。
  4. **可配置审批流（混合模型 C）**：固定主干节点带🔒「规则锁定」标识、不可删；节点间「+加签」插入点弹出成员选择浮层；底部独立「抄送人」区（chip 可增删）；右侧预览实时同步。
  5. 底部：取消 / 存草稿（写入草稿箱、计数+1）/ 提交审批。
- **草稿箱**：行内操作=编辑/删除；点行回到表单（标题回填）；删除减计数、清空显示空状态。

### 5.4 组织与人员管理（`组织成员.html` + `.js`）
- **用途**：管理员管理组织架构与员工。
- **左栏部门树**：可展开/折叠的树形，节点含名称 + 人数；可搜索；选中态高亮。支持增删改、设负责人、调层级。
- **右侧成员表**：列 = 头像+姓名 / 工号 / 账号 / 部门 / 职位 / **在位状态** / 角色(可多个 Tag) / 状态 / 操作。
- **在位状态**（独立列）：在岗（默认，绿）/ 请假中（事假·病假）/ 休假中（年假·调休）/ 出差中——用 Tag + 圆点视觉编码；管理员可手动设置/清除。
- **员工详情/编辑**：抽屉或弹窗，含全部字段 + 角色分配 + 启用/停用 + 重置密码 + 是否首次登录需改密。
- **选中成员 → 调整部门**：弹出部门选择对话框（树形单选）。
- 详细数据结构见 `组织成员.js`。

### 5.5 我的待办（`我的待办.html` + `.js`）—— Lark Tasks 复刻
- **用途**：聚合各模块需我处理的事 + 个人任务。
- **三栏**：左清单栏（智能视图 + 我的清单）/ 中任务区 / 右详情面板（浮层，不挤压列表）。
- **清单栏可折叠**：折叠后**中栏完全消失**（宽 0），展开按钮移到内容区标题左侧；**hover 展开按钮浮出缩略列表**（图标+文字+计数，点项跳转且保持折叠）。
- **工具栏**（Lark 式一行）：「新建任务」蓝色分裂按钮（主+下拉）+ 状态(全部/未完成/已完成) + 筛选(仅逾期/有无截止，带数字角标) + 排序(拖拽自定义/截止时间/创建时间) + 分组(自定义/按时间/按状态) + 字段配置(勾选显示列)。每个都是真实下拉，按钮文字反映当前选择，点外关闭。
- **列表 = 列表格**：列 = 任务标题(含复选圈、清单色点、子任务进度、来源 Tag) / 截止时间 / 负责人。分组分区（可折叠），每组底部「+新建任务」**就地新建**（标题输入 + 截止日期，回车创建并保持聚焦连续添加）；所有分组下「+新建分组」就地建组。
- **拖拽**：自定义分组 + 拖拽排序模式下，个人任务行可拖（蓝色插入指示线，同组重排 / 跨组移动）；分组标题可拖（hover 出六点手柄）排序，「已完成」固定底部；系统待办不可拖；其它排序模式关闭拖拽；单击 ≠ 拖拽。
- **详情面板**（右滑，宽 384px，列表让出右内边距 408px 过渡 .26s）：扁平 Lark 风字段——负责人(头像) / 清单 / 开始时间 / 截止时间 / 提醒 / 重复（值为纯文本+hover 浅底，空值「添加XX」灰占位，日期显示「6月4日 周四 18:00」）+ 描述 + 子任务(进度条) + 附件 + 评论/动态 + N人关注。**无优先级字段**。
- **完成动画**：勾选 → 对勾弹一下(scale 关键帧) + 标题划除 → 行淡出折叠(max-height .3s) → 移入「已完成」。
- **空状态**：剪贴板插画 + 柔光 + 角标，分语境——今日清空(蓝+新建CTA) / 搜索无果(灰放大镜) / 无已完成(绿对勾)。
- 全部任务数据与逻辑见 `我的待办.js`。

### 5.6 消息中心（`消息中心.html` + `.js`）—— 飞书三栏
- **用途**：消息与会话集中处理。
- **三栏**：左分类导航（可折叠）/ 中消息列表 / 右详情。
- **详情自适应**：聊天类消息→聊天框；审批/系统类→该类型详情卡。
- **消息列表**：未读红点 + 已读置灰；「只看未读」切换；「全部标记已读」；单条删除/归档；按时间分组（今天/昨天/更早）。
- **IM 聊天**：消息气泡（自己 vs 对方左右分布）+ 发送者名/时间；**hover 气泡侧旁浮出操作条**（垂直居中，自己的在左、对方的在右，朝内展开）：回复(引用) / 表情回应(reactions) / **添加任务**；支持撤回、发图片、emoji。
- **消息→任务联动**：聊天消息操作条「添加任务」→ 弹出创建任务对话框（标题预填消息内容、显示来源、可设截止/负责人）→ 写入 localStorage `todo_inbox_from_msg` → 我的待办页加载时收取进「收集箱」，任务详情显示蓝色「来源」卡片。
- **通知设置**：抽屉，各类消息开关 + 免打扰。
- 全部数据与逻辑见 `消息中心.js`。

## 6. 顶栏共享组件（已实现，跨 5 模块一致）

### 6.1 全局搜索（`search.js`）
- 注入选择器 `.topbar .search-box input`。输入弹出**分组结果浮层**（审批/成员/任务/消息/应用/页面），命中关键词 `<em>` 高亮，底部键盘提示。
- 点结果 `location.href` 跳对应模块 HTML。
- **键盘**：↑/↓ 移动高亮、Enter 打开、Esc 关闭；**⌘K / Ctrl+K 全局聚焦**。
- **模块可注入本页实时来源**：定义 `window.gsLocalProvider(q)` 返回 `[{title,sub,id}]` 形成「本页」分组，并定义 `window.gsLocalPick(id)` 处理点选（我的待办→打开任务详情；消息中心→打开会话，均不跳页）。
- 演示用跨模块索引硬编码在 `search.js` 顶部 `INDEX`；真实实现应替换为后端搜索 API。

### 6.2 通知下拉 + 头像菜单
- 铃铛点击展开通知浮层：标题 + 「全部已读」+ 通知项（彩色图标 + 富文本 + 时间 + 未读红点）+ 「前往消息中心」。
- 头像点击展开用户菜单：用户卡片（头像 + 姓名 + 在位状态 Tag + 部门/邮箱）+ 菜单项（个人信息 / 设置在位状态 / 偏好设置 / 退出登录）。
- 二者互斥、点外关闭。实现为自包含 IIFE，函数前缀 `tb*`（`tbTogglePop` / `tbRenderNotif` / `tbClearNotif`）避免命名冲突。真实实现应接后端通知 API。

## 7. 基础组件库（Components）

> 完整可视化见 `企业工作台设计规范.html`。下列为关键规格。

### 按钮 `.btn`（高 32px，圆角 `--r-sm`，14px/500，过渡 .15s）
| 变体 | 默认 | hover | active | disabled |
|---|---|---|---|---|
| `.btn-primary` | 背景 `--blue-500` 白字 | `--blue-600` | `--blue-700` | `--blue-disabled` |

## 9. 交互与行为（Interactions & Behavior）

- **导航**：侧栏菜单项跳各模块 HTML（真实实现用 router）。侧栏折叠状态、待办播放位等用 localStorage 持久化。
- **过渡**：抽屉 `.26s cubic-bezier(.4,0,.2,1)`；浮层/下拉 `.15~.16s` 淡入 + translateY(-6px)→0；折叠 `width .22s ease`；完成动画 `max-height .3s` + 对勾 scale 关键帧。统一克制，无花哨。
- **弹层关闭**：一律支持点遮罩/点外部 + Esc；多层时 Esc 逐层关闭。
- **表单校验**：必填项空提交→红框 + toast 提示拦截（如驳回理由、转交人）。
- **键盘**：⌘K/Ctrl+K 聚焦搜索；搜索浮层 ↑↓/Enter/Esc。
- **持久化 / 跨页**：消息→任务通过 localStorage `todo_inbox_from_msg` 传递（真实实现用后端/状态库）。
- **响应式**：桌面优先；数据卡片网格在 ≤1080px 退为 2 列、双栏区退为单列。
- **reduced-motion**：实现时建议对完成动画/入场动画加 `@media (prefers-reduced-motion)` 降级。
