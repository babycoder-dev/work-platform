# 前端外壳重做 + 设计体系 — 设计方案

- 日期：2026-06-01
- 状态：已确认（待落地）
- 范围：`apps/workbench-shell` 外壳 + `packages/ui` 设计体系
- 工作流：混合（claude.ai 探视觉方向 → 在 repo 落地代码）

## 1. 背景与动机

当前 `workbench-shell` 是一个"能跑的毛坯"：深色侧边栏 + 极简全局 CSS（`apps/workbench-shell/src/styles.css`），
`packages/ui` 几乎为空（仅一个占位类型 `placeholder-types.ts`）。没有设计系统，没有 UI 库依赖，
因此重做的沉没成本极低，不需要拆除旧体系。

目标是参照飞书的布局范式与交互模式，做一套**亮色、蓝色主调、大量留白、圆角卡片**的企业内网工作台界面，
并沉淀成可复用的设计 token + 基础组件。

## 2. 目标 / 非目标

### 本期做

- 重写应用外壳：左侧导航、顶栏、内容区框架。
- 重写登录页与工作台首页。
- 在 `packages/ui` 建立设计 token（CSS 变量）与基础组件。
- 视觉气质：飞书同款亮色蓝调。

### 预留 / 本期不做

- **业务模块页面改造**（`modules/presence/web`、`modules/platform/web` 的角色管理页等）：
  本期只建体系，业务页之后单独切片逐个迁移到新组件。预留点：组件 API 设计时要考虑这些页面的复用场景，但不在本期实现。
- **暗色主题**：token 用 CSS 变量组织，为将来加暗色留出结构，但本期只交付亮色。
- **`packages/http-client`**：不在本次范围内（当前有 M5-3 的进行中改动，互不重叠）。

## 3. 工作流（混合）

1. **探视觉方向**（用户在 claude.ai 进行）：用户提供飞书截图 + 下方提示词，让 claude.ai 产出带真实 token 的自包含 HTML 稿。
2. **落地**（本仓库，由我执行）：依据用户回传的 HTML/截图，在 `packages/ui` 建 token + 组件，并重写 `workbench-shell` 外壳与登录页。

关键约定：**设计 token 的取值以截图提取为准**。本文 §5 给出的取值是凭记忆写的近似起点/兜底，
最终值由 claude.ai 从真实飞书截图中提取、并经用户确认。

## 4. 布局结构（飞书范式）

- **左侧导航**：约 `220px`，亮色/浅灰底；选中态用主调蓝高亮 + 浅蓝背景。菜单项来自模块 manifest（不在外壳硬编码）。
- **顶栏**：左侧页面标题/面包屑；右侧搜索、通知、用户头像菜单。
- **内容区**：页面底色浅灰 `#F5F6F7` + 白色圆角卡片，强调留白。
- **登录页**：居中卡片，账号 + 密码 + 登录按钮，干净克制。
- **工作台首页**：内容区放数据卡片 + 示例表格，体现真实排版密度。

注意：外壳通过模块注册表（`module-registry`）感知模块，菜单/路由/权限来自 manifest，重做时保持这一接缝不变。

## 5. 设计 Token（起点 / 兜底，最终以截图提取为准）

- 主调：`#3370FF`，hover `#245BDB`，浅底 `#E8F0FF`
- 文字：主 `#1F2329` / 次 `#646A73` / 弱 `#8F959E`；边框 `#DEE0E3`
- 底色：页面 `#F5F6F7`、卡片 `#FFFFFF`
- 语义：成功 `#34C724` / 警告 `#FF8800` / 错误 `#F54A45`
- 圆角：`6 / 8 / 12`
- 间距阶：`4 / 8 / 12 / 16 / 24 / 32`
- 字号：`12 / 14 / 16 / 20 / 24`
- 字体：`PingFang SC, Microsoft YaHei, system-ui`

落地形态：在 `packages/ui` 用 CSS 变量定义 token；组件样式尽量 scoped，避免污染业务页过渡期观感。
与 repo 现有"无 UI 库、纯 CSS"路线一致，不引入重型依赖。

## 7. claude.ai 阶段：截图清单与提示词

### 截图（4 张必给 + 1 张可选）

1. 工作台首页 + 左侧导航（含一个选中的菜单项）— 布局骨架、导航宽度、主调蓝、留白节奏
2. 一个列表 / 表格页 — 表格密度、行高、Tag、次级按钮、分页
3. 一个表单 / 详情页 — 输入框、表单项间距、标签、圆角
4. 顶栏 + 用户头像菜单展开 — 顶栏高度、下拉菜单、头像、图标风格 5.（可选）一个主按钮明显的局部，或登录页 — 主按钮填充/hover、强调色精确值

截图要求：用原图不压缩、截亮色默认主题、尽量包含主调蓝出现处（选中导航/主按钮/链接）。

>
> 请输出**一个自包含的 HTML 文件**（内联 CSS，可在浏览器直接打开预览），包含以下内容：
>
> 1. **设计 Token 区**：请**从我附上的截图中提取真实的配色**（主色、中性灰阶、语义色）、间距与圆角节奏，定义成 CSS 变量，并在页面顶部用色板可视化展示。如果某个值截图里看不清，就用蓝色主调 `#3370FF` 一族作为兜底。
> 2. **登录页**：居中卡片，账号 + 密码 + 登录按钮，干净克制。
> 3. **应用外壳**：左侧导航栏（约 220px，浅色底，含若干菜单项与选中态）+ 顶栏（标题/面包屑 + 搜索 + 通知 + 用户头像菜单）+ 内容区（浅灰底 + 白色圆角卡片）。
> 4. **工作台首页**：内容区里放几张数据卡片 + 一个示例表格，体现真实排版密度。

> 要求：间距和层级克制专业，像飞书一样"轻"；不要 AI 味浓的渐变和花哨阴影；所有文案用中文。先给我一版完整的，我再逐步调整。

## 8. 落地步骤（回到本仓库后）

1. 在 `packages/ui` 建 token（CSS 变量）与基础组件，导出于 `packages/ui/src/index.ts`。
