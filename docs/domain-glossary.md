# 领域术语表

本文档定义跨平台基建和业务模块复用的核心术语。它不替代具体 RFC；当某个模块需要更细规则时，以该模块 RFC 为准。

## 1. 平台基础

| 术语          | 定义                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 企业          | 系统内的最高业务组织边界。首期按单企业部署设计，但数据结构保留 `enterprise_id`。                                         |
| 部门          | 企业内组织单元。部门可以有上下级关系。                                                                                   |
| 员工          | 企业内部人员的业务身份，归属一个企业和部门。                                                                             |
| 内部账号      | 员工用于登录系统的账号凭据。账号与员工身份由 Platform Core 维护。                                                        |
| 角色          | 权限点和数据范围的组合。用户通过角色获得权限。                                                                           |
| 权限点        | 形如 `<module>:<resource>:<action>` 的最小授权单元。                                                                     |
| 数据范围      | 当前用户能访问哪些员工或部门数据的约束，包括 `self`、`department`、`department_tree`、`company`、`custom`。              |
| 模块 manifest | 业务模块声明自身权限、菜单、API prefix 和 Web entry 的契约。                                                             |
| 审计日志      | 对登录、平台写操作和关键业务写操作的可追踪记录。                                                                         |
| 领域事件      | 模块内业务事实发生后的事件，例如 `presence.status.changed`。业务模块只发布可追踪事件，真实通知推送由通知基建（M7）承载。 |
| 档案写收口    | Platform Core 中唯一负责员工档案写入的 service 方法；本人窄写、管理写、未来注册审核 / 批量导入都必须复用同一授权和审计路径。 |
| profile 写授权范围 | 使用 `profile` 数据范围决定某次员工档案写操作能否作用于目标员工；越权目标按不存在处理。                              |
| 注册状态      | `platform.employees.registration_status` 预留列，取值 `active | pending`；M8-2a 本期恒 `active`，不进入 API 契约。       |

## 2. 在位管理

| 术语     | 定义                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 在位状态 | 员工在某个时间点的工作状态，例如在岗、出差、外出调研、外出、休假。       |
| 状态记录 | 员工在一个时间区间内的在位状态登记记录。                                 |
| 当前状态 | 对某个查询时间点生效的状态记录计算结果；没有生效记录时默认为 `working`。 |
| 在位看板 | 按数据范围展示员工当前状态的列表或看板视图。                             |
| 状态登记 | 员工或有管理权限的人创建、取消或修正状态记录的操作。                     |
| 状态冲突 | 同一员工存在重叠的未取消非在岗状态记录。M4 首期必须拒绝此类冲突。        |

## 3. 审批

| 术语     | 定义                                           |
| -------- | ---------------------------------------------- |
| 审批实例 | 一次业务审批流程的运行实例，例如一次请假申请。 |
| 审批任务 | 分配给某个审批人的待处理节点。                 |
| 审批动作 | 审批人执行的通过、驳回、转交等操作。           |

审批模块的详细语义在 M11 RFC 中定义（2026-05 重规划后审批为 M11，见 `docs/adr/0005-product-replan-roadmap.md`）。

## 4. 工作汇报

| 术语     | 定义                                       |
| -------- | ------------------------------------------ |
| 日报     | 员工按日提交的工作内容、问题和计划。       |
| 周报     | 员工按周提交的工作总结和计划。             |
| 汇总上报 | 按组织层级聚合下属日报或周报并向上级展示。 |

工作汇报模块的详细语义在 M10 RFC 中定义（重规划后日报为 M10，周报预留；见 `docs/adr/0005-product-replan-roadmap.md`）。

## 5. 动态表单与文件

| 术语       | 定义                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 表单槽位   | 由 contract 预注册的业务填报位置，例如员工档案、某种在位状态、日报。用户不能凭空创建任意槽位。 |
| 表单定义   | 某企业在一个固定槽位下当前启用的字段集合。                                                     |
| 字段定义   | 字段 key、标签、类型、必填、说明、顺序和可选项等配置。                                         |
| 表单记录   | 某次填报产生的记录，绑定槽位、subject 与提交时看到的 definition revision。                      |
| 记录值快照 | 表单记录保存的字段值及当时的 label / type / display 快照；后续修改字段不会让旧记录失去语义。    |
| 文件对象   | Files 模块保存的私有文件 metadata 与 opaque storage key；业务记录只引用 fileId，不保存磁盘路径。 |

动态表单 mini 与文件存储的详细语义见 `docs/rfc/m6-dynamic-forms-file-storage.md`。
